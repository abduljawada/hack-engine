Find your first value

This local practice game keeps its score in WebAssembly memory. It does not send data anywhere.

Score 100

  1. Open Hack Engine from the browser toolbar and pin its panel.
  2. Search for the score shown above using Exact value.
  3. Spend 7 points, enter the new score, then choose Next scan.
  4. Select the remaining address and write 500.
  5. Try Restore last write, or freeze the score and spend again.
  6. Use Stop all freezes when you finish. A hidden practice tab stops freezing automatically.

To practice Undo scan, refine with a deliberately incorrect score, then select Undo scan.
