# Security policy

## Reporting a vulnerability

Please do not disclose an unpatched vulnerability in a public issue. Use GitHub's private vulnerability reporting flow for the repository:

<https://github.com/abduljawada/hack-engine/security/advisories/new>

Include the affected version, browser, reproduction steps, expected impact, and any suggested mitigation. Do not include passwords, private browsing data, proprietary game files, or memory dumps containing information you are not authorized to share.

Ordinary bugs and compatibility reports can use the public issue tracker:

<https://github.com/abduljawada/hack-engine/issues>

General support questions can also be sent to <a.abduljawad@outlook.com>.

## Supported versions

Hack Engine is pre-1.0 software. Security fixes are applied to the latest published version; older development builds are not supported.
